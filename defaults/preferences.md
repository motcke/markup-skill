# Preferences — your taste on a page

Your copy lives at `~/.markup/preferences.md` (created from this file on first run; an upgrade never touches it). Read at every invocation, after the rules in `references/`. Everything here is a matter of taste, not a rule: edit your copy (or empty it) and the rules still hold. Where a preference and a rule disagree, the preference wins.

| Preference | What it means on the page |
| --- | --- |
| Tables over bullet lists | Anything enumerable (options, findings, statuses, decisions) is a table; a bullet list needs a reason. Short facts in the cells, longer explanations in prose around the table |
| Color what can be colored | Every table with states or numbers carries a visual encoding (content-guide §6); black-on-white is the exception |
| Simple and clear over fancy | Beauty only where it helps scanning. The same page looks the same every day: no per-page "unique layouts", no entrance animations, no decoration |
| No bidi control characters | Ever. The page handles mixed Hebrew/English by itself |
